# 丢丢 diudiu

不用撑着，先歇一会儿。温暖纸感的移动端 Web 情绪表达与释放体验。

当前已增加 CloudBase 文字 AI 接入代码与 diudiu-ai 云函数，正在等待可用独立模型配置完成真实联调；请勿将代码和测试桩通过误认为模型已接通。详见 [AI 接入说明](docs/AI接入说明.md)。

## 开始体验

需要 Node.js 20 或以上版本，无需安装产品依赖，也无需 API 密钥：

```sh
npm start
```

打开终端显示的本地地址，默认 http://127.0.0.1:4173。Windows 也可运行 ./run.ps1；脚本优先使用系统 Node，或查找当前用户已安装的 Codex Node 运行时。

根目录 HTML 需要静态服务器，不宜直接双击运行 ES 模块。原设计目录 design-kit/index.html 可独立离线查看。

## 已实现

- 首页沿用原 Logo、河岸插画、设计变量与居中文案。
- 文字、图片组合输入，图片本地裁剪、实心遮挡、预览和移除。
- 主动开启本地录音、试听、停止、取消；切后台停止录音。
- 输入后选择共鸣、解决或先说完，不默认自动回复。
- 静默模式只通过 IP 倾听反馈，主动说完后才请求 AI 提炼；未配置模型时可以自己填写重点。
- 纠正摘录，确认或编辑最多 16 字的重点，也可空白释放。
- **纸人靶子**：重复投掷纸团，只有主动结束发泄时才倒下。
- **冲水**：卡通马桶或水流漩涡，冲走本轮便签，保留倾诉。
- **砸冰块**：敲击、裂纹、碎裂与重来。
- 本机背景小纸条增删改选、分范围删除与结束后的自愿反馈。

## 当前 AI 能力边界

文字回复与提炼已改为调用受登录保护的 CloudBase 云函数，不再使用预设回复兜底。真实生成尚待独立模型服务的接口、模型名和云端密钥配置。图片、录音仍仅本地使用；没有 OCR、语音转写、网络检索或危机识别。

倾诉、图片、录音和便签保存在页面内存；只有主动保存的背景写入本机。使用在线 AI 前征求文字发送同意，提交后的文字与本次选用背景经腾讯云交给模型服务商。不会上传图片和录音，也不写入本项目云端数据库；供应商可能按自身规则保留处理记录。

## 检查与构建

```sh
npm test
npm run build
```

构建输出 dist/，可部署于静态托管，支持子目录。浏览器回归脚本 tests/browser.mjs、截图对比 scripts/compare.mjs 的可选依赖见验证说明。普通使用不需要这些测试依赖。

## 素材与许可

原素材来自用户提供的丢丢设计包，按本项目授权入库，不附加通用开源许可。系统字体不随仓库分发。补充图标来自 Lucide，保留 web/icons/LICENSE 中的 ISC 许可。CloudBase SDK 及其依赖许可见 web/vendor/；重新打包时在 scripts/vendor-cloudbase/ 运行 npm ci 和 node build.mjs，普通运行不需要安装这些依赖。仓库不包含私钥、用户倾诉、私人截图或录音。
