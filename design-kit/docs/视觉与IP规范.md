# 丢丢｜沿用的视觉与 IP 规范

## 9. 视觉系统与开发规范

设计参考视口为 390×844 CSS px，实际 PNG 保留生成原生尺寸，切图中首页与流程页像素倍率不同，开发时不要照搬 PNG 像素尺寸。

| 项目 | 规范 |
|---|---|
| 背景 | #FFF8ED，主要输入/文字区使用低纹理纯色 |
| 文字 | 深可可 #4C2B18；次级文字 #805C43 |
| 交互主色 | #B9572F；白字按钮优先用此较深色，插画可用更浅的陶土色 |
| 辅色 | 鼠尾草 #8A9460、冰蓝 #A6C1CD，只用于图形和辅助背景 |
| 正文 | 16px，行高约 1.65；辅助文字至少 14px |
| 标题 | 24–28px，首页可 32px；不把所有表单标题做成海报大字 |
| 字体 | 使用系统中文无衬线；生成图中的手写风格不等于随包附带了字体授权 |
| 间距 | 4/8/12/16/24/32；左右边距约 20px |
| 触控 | 目标至少 44×44px；主要按钮至少 52px 高 |
| 圆角 | 12/16/24px；避免所有信息都被包进层层卡片 |
| 动效 | 状态反馈约120ms，转场约240ms，仪式约1.2–3秒；可减少或关闭 |
| 对齐 | 首页倾听和释放文案共用屏幕中心轴；图标位置不能改变文字整体轴线 |

手机键盘出现时：输入区上移到可视区域，消息区滚动，主要发送控件可达；不让固定插画压住输入框。适配底部安全区，优先使用动态视口高度，避免仅以固定 100vh 处理键盘。

图标开发时选一个一致的成熟图标库，线宽与大小统一；截图中的图标不是已经拆好的生产 SVG。图形资产是 RGBA PNG，不能把 PNG 包在 SVG 里称为矢量版。

## 10. 纸团 IP 情绪板与动作规范

### 10.1 角色定义

暂用名称「丢丢纸团」。它是温和、轻巧、能容纳不整齐表达的纸团伙伴，纸张不完美的折面是主要识别点。形体是一个完整纸团，不额外添加人类头身比例、耳朵或尾巴。颜色保持奶油纸面、可可四肢、桃色腮红；小尺寸优先保留轮廓和表情，弱化纸纹。

### 10.2 情绪板

| 文件 | 表情 | 合适用途 |
|---|---|---|
| calm.png | 平静 | 默认、首页、输入前 |
| happy.png | 开心 | 用户主动选择的积极状态、轻量完成 |
| sad.png | 难过 | 情绪表达素材；不作为退出挽留 |
| tired.png | 疲惫 | 休息提示、用户主动表达累 |
| frustrated.png | 烦躁 | 共鸣式表达，不指向现实攻击 |
| surprised.png | 惊讶 | 轻度意外反馈，不用于安全警报 |
| relieved.png | 松一口气 | 用户自己选择「轻一点」后的反馈 |
| thoughtful.png | 思考 | 生成/整理候选，不暗示真人在线 |

不依据聊天内容自动给用户贴情绪标签或诊断；表情只是界面表达，不是模型判断用户状态的证明。

### 10.3 动作姿态

| 文件 | 动作 | 推荐用途 |
|---|---|---|
| wave.png | 招手 | 首次欢迎 |
| listen.png | 倾听 | 倾听页静态角色 |
| nod.png | 点头 | 已收到用户纠正，不代表认可全部事实 |
| crumple.png | 揉纸团 | 便签进入仪式的过渡 |
| throw.png | 投掷 | 投掷入口和关键反馈 |
| gentle-shake.png | 轻摇 | 运动权限前说明 |
| stretch.png | 舒展 | 可选休息与收尾 |
| hold-note.png | 拿纸条 | 背景列表与保存候选 |

这些是 8 个独立静态姿态，不是可直接播放的完整动画序列，也不是已经绑定骨骼的素材。可以先在开发中做整体轻微位移、旋转、透明度转场；需要自然揉纸、投掷等连续动画时，应按统一角色比例补绘过渡帧。图集不同姿态的身体朝向与脚的位置略有变化，不能用简单翻页冒充流畅动画。

## 11. 素材目录与使用方法

- ui/screens/：00–20 独立页面 PNG。
- ui/boards/：按旅程组织的 5 张总览。
- assets/brand/：横版、图形标、文字标与512图标。
- assets/ip/emotions/：8 张情绪，均512×512透明。
- assets/ip/actions/：8 张姿态，均512×512透明。
- assets/props/：纸球、纸人靶、马桶、漩涡、完整冰、裂冰、信封、纸飞机。
- assets/scenes/home-river-hero.png：从指定首页裁出的原河岸插画；带背景，不是透明分层场景。
- sources/：原始参考和生成原图，方便重做切图。
- docs/asset-manifest.json：单张素材路径、尺寸和原图裁切区域。
- docs/design-tokens.json：工程颜色、字体、尺寸与动效建议。
- docs/生成提示词.md：生成依据和准确提示词记录。

素材经按格拆分、等比缩放与透明留白，没有用程序重绘角色。保留原始图以便进一步统一比例和商业级精修。不要放大超过原始分辨率后当成高清矢量素材。
