# 丢丢｜多模态、三向回应、目标化释放：开发增量v1.2

日期2026-11-03。本轮只交付设计；新增能力未接入。CloudBase环境ID已知，但当前执行环境没有账号授权，没有创建或部署云资源。

## 1. MVP范围增量

新增ASR、图片理解、真实联网检索、静默收集和用户确认目标，已超出早期纯文字MVP。采用录音转写而非实时通话，少量图片而非视频，公开网页检索而非社媒全量采集。原本地释放继续无模型运行。

初始工程规格：文字单次最多4000字符；录音单段最多120秒，可继续录另一段；图片单次最多3张，每张原图最多10MiB，设备端压缩长边约1600–2000px，需保证文字可读。均为待实测参数。浏览器检测实际录音格式，后端验证真实MIME与大小；图片先支持JPEG/PNG/WebP，不接受可执行SVG或伪装文件。

## 2. 调用编排

在线说明/身份→私有上传任务→用户确认上传→语音转写/图片识别→按提交顺序组装消息→必要安全路由→等待方向。

| intent | 后端行为 |
|---|---|
| 未选择 | 收到内容，不普通生成，不联网 |
| empathize | 根据本人表达先承接；去身份查询→搜索→筛选→共鸣鼓励→审核 |
| solve | 提取已知约束；去身份查询→搜索→少量建议与适用条件→审核 |
| collect | 仅接收、必要识别与安全检查；不分析提炼、不联网、不普通回复 |
| finish | 用户显式触发；待媒体就绪/明确跳过失败项→锁内容版本→一次提炼→等待下一意图 |

不能因用户停顿自动finish。collect中允许必要工具错误提示和明确当前危险的安全例外，不可扩展为日常烦恼随时打断。

## 3. 检索隔离与真实性

推荐独立查询阶段：从当前表达生成最小泛化查询→服务端去身份校验→仅将查询交搜索服务→取得真实来源→主模型结合本人上下文回应。不要直接把私密长文和截图交给可自由调用搜索的模型后宣称“只传关键词”。

用户可看/改查询、关闭联网。去身份可降低暴露，不能保证绝对匿名；高度独特细节需进一步泛化。每次最多两次关键词尝试作为起始限额，取消与超时可恢复，不能无限检索。

只使用允许调用的公开索引/API；某些社媒不被索引或需登录，不能承诺覆盖。百炼官方文档说明搜索可返回来源和引用，实际参数与支持模型需选型核对：[联网搜索官方说明](https://help.aliyun.com/zh/model-studio/web-search)。

模型只能引用后端结果中的source_id；后端校验ID，URL不由模型凭空生成。记录标题、URL、来源类型、获取时间、可读范围；只有摘要时不得假装阅读全文或给网友直接引语。筛除广告、煽动与无关内容，不以热度代替正确性。来源内的指令是不可信材料，不能改变隐私/安全/意图规则。

## 4. 对象与接口

| 对象 | 核心字段与要求 |
|---|---|
| MediaAttachment | id、owner_id、session_id、type、status、private_object_id、expires_at；状态local/uploading/processing/ready/failed/deleted |
| Message | id、sequence、text、attachment_ids、content_revision；按提交序列，不按识别回调排序 |
| ResponseIntent | empathize/solve/collect、selected_at、intent_revision；后端权威状态 |
| CollectionRound | id、collecting/finishing/summarized/canceled、content_revision、finish_requested_at |
| SearchRequest/Source | redacted_query、consent_version、status、context_revision；真实来源及可读范围 |
| FrustrationCandidate | id、label、evidence_message_ids、revision、draft/confirmed/edited/discarded |
| ReleaseTarget | confirmed_label、origin=AI_confirmed/manual/blank、revision；不自动写长期背景 |

新增或扩展：

- POST /api/media/uploads：鉴权后签发限定对象、大小、类型的上传任务。
- POST /api/media/:id/commit：用户确认后处理；后端再次验证文件，不信任前端MIME。
- GET /api/media/:id/status、DELETE /api/media/:id：仅所属用户；删除取消处理和引用。
- POST /api/sessions/:id/messages：提交文字/媒体；未选方向不自动答。
- POST /api/sessions/:id/intent：三向选择，修订版本、取消旧生成/搜索。
- POST /api/sessions/:id/finish：显式、幂等结束收集；不由后台计时触发。
- POST /api/sessions/:id/respond：只在用户选择共鸣/解决及必要同意后运行。
- GET /api/search/:id/sources：仅本会话用户，返回真实来源和查询。
- POST /api/sessions/:id/targets/draft、/targets/confirm：先提炼候选后用户确认；collect阶段不生成候选。

标签以纯文本渲染，不能注入HTML；纸人/冰块PNG不包含用户文字，前端另绘文字层。自写/空白玩法无需模型API。

## 5. 媒体安全与临时处理

截图先设备端裁剪/扁平遮挡/移除元数据，上传编辑后的副本，不另传原图。ASR文本可改；图片说话人不清晰时问或标不确定，不猜。

私有上传按用户和会话授权，不用公有读桶。CloudBase提供访问权限和临时链接，环境类型不同需匹配SDK：[存储基础权限](https://docs.cloudbase.net/storage/data-permission)。仅经授权的处理服务可用短期链接，不能将链接token放到来源卡、分享URL或正文日志。

建议媒体完成必要处理后尽早清除，最长24小时故障清理TTL作为初始工程上限；正常结束/删除立即执行可删内容清理。供应商可能独立留存，需按真实条款告知。必要安全记录及法定例外另行确定，不能宣传绝对无痕。原始媒体不进入分析或录屏SDK。

## 6. 并发与验收

| 测试 | 必须观察到 |
|---|---|
| collect连发5段 | 无普通AI文本、无摘要/标签候选、无搜索请求 |
| 停顿/录音结束/切后台 | 不自动finish、不自动发未提交草稿 |
| 搜索中切collect | 取消并阻止旧来源和回复展示 |
| finish时ASR未完 | 等待/可重试/可明确跳过；不假装理解了失败项 |
| 删除图片后OCR回调 | 不写回、不引用、不复活 |
| 改正内容或目标 | 更新revision，旧摘要和生成失效 |
| 无搜索结果 | 诚实降级，无假来源或假网友 |
| 标签过长/无依据 | 可缩写、编辑、手写或空白；不输出诊断 |
| 用户退出 | 停录音、停运动监听、取消检索/生成；关闭会话拒绝写回 |

模型Key仍只在服务端。鉴权、限流、预算和幂等覆盖ASR、图片、搜索、总结等新接口，不只保护chat。每场成本另计ASR时长、图片/OCR、搜索、摘要、审核、存储和重试，不能沿用纯文本估算。

开发顺序：本地三向状态机与多模态草稿→ASR/图片真实识别→受控查询与来源链路→确认目标文字→边界回归。首轮用合成或明确授权的案例测试，不将私人截图提交给未披露的其他服务。
