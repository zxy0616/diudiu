# 丢丢网络检索

日期：2026-11-04。

## 已选方案与边界

沿用 CloudBase 事件云函数 `diudiu-ai` 和现有火山方舟文字模型，在模型生成前显式调用豆包搜索 Custom API。用户已开通服务并按约定配置云端变量。本次不另建 HTTP 函数、不申请平台全站搜索权限、不修改原始素材。

曾比较方舟内置工具与独立搜索步骤：内置工具由模型决定是否搜索；独立搜索可以控制检索词、平台范围和失败提示。按前文推荐并由用户配置的独立搜索路径实现。

搜索对象是已收录的公开网页。先用 `Filter.Sites` 限定小红书、微博、抖音域名，按实际返回链接再次检查平台归属；没有可用摘要或正文时，最多再查一次公开网页。不能承诺覆盖站内笔记、评论、视频字幕或需要登录的全文。

## 配置

只在 CloudBase → 当前环境 → 云函数 → **diudiu-ai** → 环境变量配置：

- `SEARCH_API_KEY`：豆包搜索专用密钥，不加 Bearer 前缀。
- `SEARCH_API_URL`：`https://open.feedcoopapi.com/search_api/web_search`。

现有 `LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL` 继续用于生成。搜索服务地址只允许上述固定官方端点，客户端不能修改；密钥不进入前端、静态构建或 GitHub。部署代码时保留现有云端变量。

## 用户控制

- 首次文字发送同意中，可审核检索词并关闭搜索。默认关键词来自有限的通用主题模板，不复制姓名、公司、电话或聊天原话；分类可能不准确，用户可手改。
- 搜索服务只收到已审核的检索词；模型服务仍处理用户同意发送的会话文字与本次选用背景。手工检索词也可能含个人信息，页面会提示避免填写。
- 来源页面可以编辑关键词、切换社交平台优先/公开网页、关闭检索；只有点击“按这些设置重新回应”后才生效。
- 先说完期间不调用模型或搜索。烦恼提炼由服务端强制关闭搜索，即使请求伪造 enabled=true 也不会调用搜索，避免把他人经历混入用户事实。
- 停止等待与切换方向继续使用原有过期结果丢弃机制，不承诺撤销已经发生的云端费用。

## 可信来源与故障

来源只由搜索 API 的实际 `WebResults` 构造，过滤危险协议、本地地址、含用户名密码的链接并去重。平台标签按实际域名识别，不相信外部 SiteName。页面按纯文本展示标题与摘要，链接独立新页打开。

仅 Summary 或 Content 进入模型参考，单条最多 1200 字；只有 Snippet 的结果标记“仅搜索摘要”，不参与生成。网络文本以不可信资料附在用户消息层，不提升为系统指令，不执行其中命令。模型使用编号引用，不输出自造网址；无效编号会移除。来源卡片属于“检索参考”，不是已读全文或事实核验认证。未对来源正文做通用抓取。

搜索失败、限流、授权问题、超时、无结果和仅摘要都有不同提示。失败时仍可继续真实文字回应，但模型收到“无可用网络材料”的限制，不降级为预设回复。

每次回应最多两次搜索，每次搜索 6 秒超时；启用搜索时模型 35 秒超时，未启用时仍为 45 秒。每用户每分钟六次与同请求去重为单实例保护，不是跨实例硬性预算。一次回应可能多消耗搜索与模型费用；本次没有变更套餐或开通超限付费。

## 验证

单元测试覆盖鉴权、静默、强制关闭提炼检索、密钥隔离、去重、搜索范围、来源安全、超时、HTTP 200 错误体和无结果。浏览器测试桩检查检索词审核、来源转义、关闭搜索和旧结果隔离，不能替代真实 API 测试。

运行 `RUN_LIVE_SEARCH=1` 的 `tests/live-cloudbase.mjs` 可用本机开发账号验证真实搜索 → 模型往返；必须取得实际搜索请求 ID、来源链接与模型 token 用量。真实结果以测试输出为准，未成功时不得宣称联网已接通。

## 本次真实验证结果

2026-11-04：虚构职场表达，使用通用检索词，1 次社交平台公开检索返回 5 条微博来源，均带正文；模型回应消耗 2576 tokens，搜索 → 模型调用成功。没有把账号密码、API Key 或用户真实倾诉写入报告。此结果不承诺其他查询同样成功。
