# 页面与素材映射

日期：2026-11-04。原包共 76 个文件、29 个页面 PNG；全部文件与 ZIP 内容的 SHA-256 一致，明细见 [素材核验.json](素材核验.json)。原包完整保存在 `design-kit/`，没有覆盖原规范和原图。

## 29 个状态对应

- **00-home**：首页；原河岸插画、Logo、居中文案与双入口，首页草稿带入倾诉。
- **01-input**：多模态输入；文字、最多 3 张图片、本地录音。没有 OCR 或转写。
- **02-direction**：首次发送后的方向弹层；关闭后保留已提交输入，可再选。
- **03-quiet**：`#conversation` 静默状态；连续输入不插入 AI 文本，显式“说完了”后提炼。
- **04-summary**：`#summary`；文本摘录示例与待确认短句，不假装完成模型分析。
- **05-empathy**：共鸣状态；标注预设回应，不主动插入行动建议。
- **06-suggestions**：解决状态；三项可展开的演示建议，允许拒绝或切换方向。
- **07-sources**：`#sources`；可编辑检索词与设置预览，不发起检索或编造链接。
- **08-search-empty**：`#search-empty`；无结果演示，可换词或不检索继续。
- **09-target-confirm**：`#target`；确认、修改或留白，最多 16 字。
- **10-paper-target**：`#game` 纸团投掷；可无限重复投掷，点击结束后靶子倒下。
- **11-ice**：`#game` 砸冰；完整冰、裂冰，敲击五次碎裂，可再来一次。
- **12-image-review**：图片检查弹层；设备端拖动裁剪、实心遮挡、预览、移除，输出扁平 PNG 副本。
- **13-correct**：纠正弹层；修改摘录与重点，旧结果不覆盖纠正。
- **14-listen-end**：`#end`；主动结束、可选感受、可选保存背景或回首页。
- **15-release-menu**：`#menu`；纸团投掷、一口气冲走、敲碎情绪冰。
- **16-release-note**：`#target` 本地手写便签；无需 AI，可空白开始。
- **17-flush**：`#game` 冲水；马桶/漩涡切换，冲走本轮便签，不删倾诉。
- **18-motion-permission**：轻摇说明弹层；没有监听运动或请求权限，说明点击替代。
- **19-release-end**：`#end`；释放后的自愿感受选择与返回。
- **20-no-relief**：`#no-relief`；可继续表达、休息或看现实支持。
- **21-context-list**：`#memories`；本机背景列表和空状态。
- **22-context-confirm**：新建/编辑背景弹层；主动确认后保存到本机。
- **23-context-use**：本次选用背景的确认弹层，可在输入页取消，不自动选用。
- **24-privacy**：`#privacy`；能力、存储、分范围删除与原设计入口。
- **25-first-use**：倾诉前说明弹层；无账号、无云服务，说明真实边界。
- **26-network-error**：没有模型或检索请求，不伪造在线失败；无来源、存储失败、文件读取失败、麦克风拒绝有本地提示和回退。
- **27-delete-confirm**：删除确认弹层；单张纸条、背景、当前倾诉、全部本地内容分范围处理。
- **28-real-support**：`#support`；可信任的人和当地紧急支持提示，不虚构热线或风险自动识别。

## 工程与生成稿的区别

原 `design-tokens.json` 明确工程变量优先于生成图像素与字体形状。Web 使用其颜色、16px 正文、系统中文字体、44px 触控目标、52px 主要按钮，不分发未附许可的商业字体。

整页生成图中的纸人是立腿轮廓，独立 `paper-target.png` 则是底座轮廓；马桶视角、背景分层也不同。交互使用原包独立透明素材和唯一可用河岸场景，保留这些原始差异。生成页面中烘焙的示例烦恼文字不会带入玩法，用户文字是可编辑 HTML 层。

静默模式支持持续增加消息，页面高度随内容变化。键盘、录音权限和图片编辑是浏览器交互，不用 PNG 假装可用控件。

## 素材用途

- `design-kit/assets/brand/`：4 个 Logo，页头和站点图标。
- `design-kit/assets/scenes/home-river-hero.png`：首页、倾诉与玩法场景。
- `design-kit/assets/ip/actions/`：8 个静态姿态，倾听、背景、结束等状态。
- `design-kit/assets/ip/emotions/`：8 个表情，玩法陪伴、无结果、自主感受反馈。
- `design-kit/assets/props/`：8 个道具，纸人、纸球、马桶、漩涡、完整冰、裂冰、纸飞机、信封。
- `design-kit/ui/`、`design-kit/sources/`：原页面、总览和原图，可从原离线目录浏览。
- `web/icons/`：Lucide 官方图标路径和 ISC 许可，补充界面图标，没有重绘 IP。

原素材保持 PNG 格式，不宣称是矢量或连续动画。公开仓库不包含用户录音、私人截图或浏览器存储。
