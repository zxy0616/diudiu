## 运行检查

使用 `npm test` 和 `npm run build`。可选浏览器验证 `tests/browser.mjs` 使用 Playwright，支持环境变量 `PLAYWRIGHT_MODULE`、`CHROME_PATH`、`TEST_URL`；不会写入私人数据。可选截图比较 `scripts/compare.mjs` 使用 Sharp，支持 `SHARP_MODULE`。

本次使用环境已提供的 Node、Chrome、Playwright 和 Sharp。普通运行产品不需要安装测试依赖；CloudBase 浏览器 SDK 及依赖已打包为仓库本地文件，没有 CDN 请求。

## 文字 AI 增量

19 项单元测试通过。浏览器 AI 合约测试使用明确的测试桩，检查发送同意、静默零调用、过期响应丢弃、失败与重试和主动提炼；测试桩不构成真实模型联调。原三种释放方式和合成媒体回归已重跑。

CloudBase 测试域名首次访问会显示平台提示页，需要等待后点击“确定访问”。tests/live-cloudbase.mjs 会处理这一平台页面，并使用本机忽略文件中的开发账号验证实际登录与云函数状态；只有配置真实模型并设置 RUN_LIVE_MODEL=1 后，才检查实际 token 用量的回应与提炼。

搜索增量：tests/browser-search.mjs 的测试桩验证检索词审核、来源转义、搜索开关、静默和提炼边界；真实搜索测试取得 5 条微博来源、1 次搜索及 2576 模型 tokens。
