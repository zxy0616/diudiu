## 运行检查

使用 `npm test` 和 `npm run build`。可选浏览器验证 `tests/browser.mjs` 使用 Playwright，支持环境变量 `PLAYWRIGHT_MODULE`、`CHROME_PATH`、`TEST_URL`；不会写入私人数据。可选截图比较 `scripts/compare.mjs` 使用 Sharp，支持 `SHARP_MODULE`。

本次使用环境已提供的 Node、Chrome、Playwright 和 Sharp。普通运行产品不需要安装测试依赖，产品零第三方 JavaScript 运行依赖，没有 CDN 请求。

## 验证限制

- 未运行 iOS Safari、Android 真机；软键盘、安全区和硬件权限需真机验证。
- 未验证真实麦克风音质、各种编码或长时录音，不将 UI 可用等同于设备兼容性通过。
- 没有真实 AI、ASR、OCR 和检索，相关服务不在通过范围。
- 原道具与整页生成稿有轮廓和视角差异，详见页面映射，不宣称整页像素级一致。
- 没有登录、云端保存、危机识别和真实运动传感器。
