# 丢丢：更自然的倾诉与小纸篓

本次按用户已明确给出的完整功能清单实施。补充确认：小纸篓仅保存在本机浏览器，同一浏览器下次继续；不新增云端历史。CloudBase 拒绝原定密码后，用户已确认合规密码，普通应用账号已创建；凭据不写入源码、静态产物和文档示例。

## 方案与约束

保留当前原生模块 Web、CloudBase 事件云函数、独立火山模型和豆包搜索，不引入新前端框架或额外付费服务。沿用现有奶油底 #FFF8ED、浅纸色 #FCEBD7、棕墨 #4C2B18、陶土色 #B9572F、鼠尾草 #8A9460 以及系统中文字体和 20px 侧边距。

小纸篓比较过云端历史与本机保存：用户已选本机。工程选择 IndexedDB 保存文字与媒体 Blob，避免把临时 blob URL 或大图塞进 localStorage；保留现有背景小纸条存储。保存完全自愿，不在后台自动归档。默认保存本次文字与回应；图片和录音可在保存时选择一并留下。上限 50 团、每团附件 20 MiB，失败时原记录和当前会话保留。

主页增加小纸篓入口。小纸篓上方是主题搜索与可切换的标签，主体是错落的纸团双列，复用纸团 PNG；每团显示标题、日期、少量标签，打开后能看完整文字与保留的附件，选择继续说或碎纸。碎纸需明确确认，只删除对应记录和媒体，不触及其他记录。支持空态、无匹配态、禁用存储与额度不足。

## 倾诉与回应

第二个方向统一叫“想要解决”，保留三个选择与随时切换。根据问题与情绪线索给出可更改的方向推荐，例如“为什么找不到工作”偏解决，“导师好苛刻”偏共鸣；明确选择的方向优先，不因自动识别强行改向。先说完不发分析或检索请求，只显示纯色对话背景与 IP 点头，不复用首页河岸图。

对话按时间保存双方消息。最下方按钮统一“就说到这儿吧”；结束后显示“丢丢正在整理你的烦恼”，返回事件概括、几个可多选的烦恼重点、标题与自动标签。允许自写重点、留白释放。多选保留完整选项，道具上轮流显示各项，单条最多 16 字，不把多项强行截断成一条。

服务端对可回应模式先做一次受约束的文字分析，输出主题、方向、关键词和通用检索组合，搜索至多两组关键词。搜索只发送去标识化的主题词，不把整段倾诉直接作为查询。静默与总结路径不检索。搜索失败不阻断自然文字回应，不伪造来源。外部资料为不可信数据，不进入系统指令层。

所有生成的对人称谓使用“你”，不写“用户”。语气具体、温和、积极共情，先接住当下表达；不给盲目乐观或固定鸡汤，不诊断、不说教、不假装真人，不解释内部分类和处理路径。请求失败仍用朴素的可操作文案，保留必要的隐私同意和当前能力边界。

## 归档与继续

整理与发泄结束后可打开保存表单：标题、自动标签、自定义标签、是否保留图片录音。自动标签来自本次分析/总结，可移除；自定义标签去重、限长。未成功分析时可以手动写标签，不能冒充已完成分析。

保存后返回小纸篓或首页。继续说恢复该团的历史、附件、重点和标签，不自动发送历史；下一次主动发送再使用近期上下文，避免超过模型限制。再次保存更新同一团，不重复创建。删除当前保存记录后，内存会话不自动重建该记录，只有再次主动保存才创建新团。

隐私页删去设计目录和策划案入口，改用简明的人话说明保存、删除与联网。技术细节留在仓库文档。新的登录账号为普通应用账号，不赋管理员角色，也不修改全环境密码策略。

## 验证

验证账号实际登录；模型真实返回第二人称概括、多选重点、自动标签与关键词；真实搜索来源有效。单元测试覆盖结构校验、静默、显式方向优先、上下文裁剪、标签与存储错误。浏览器覆盖多选、保存/刷新/筛选/继续/更新/碎纸、附件保存、旧请求隔离、纯色倾听、移动宽度与三个释放玩法。原始设计包不修改，所有新状态用原素材与 CSS 完成。
